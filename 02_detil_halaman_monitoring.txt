1. TOP NAVIGATION & FILTER BAR
----------------------------------------------------------------------
- Target Selector Dropdown:
  * Nampilin daftar nama target beserta ikon tipe (Server/Web/DB/API)
  * Badges indikator status kecil (Hijau = UP, Merah = DOWN)
- Time-Range Filter Controller:
  * Quick Buttons: [1H] [24H] [7D] [MTD] [YTD]
  * Custom Date Range Picker: Modal kalender untuk pilih rentang tanggal spesifik
  * Indicator Subtext: Penanda skala data DB (misal: "Scale: Raw Data" / "Scale: Hourly Avg" / "Scale: Daily Avg")
- Tombol Notifikasi Telegram: Shortcut "Telegram Alert" untuk modal konfigurasi Bot Token & Chat ID routing.
- Tombol Manajemen Target: Shortcut "Kelola Target" untuk buka modal CRUD.
- Profile & Logout: Avatar user + Tombol Logout.


2. TOP STAT CARDS (HEALTH & METRICS SNAPSHOT)
----------------------------------------------------------------------
Card 1: Overall System Status & Heartbeat
  - Label: Status Target
  - Visual: Status Text ("ONLINE" / "OFFLINE") + Animated Pulse Dot (Neon Green / Red)
  - Subtext: Duration Status (misal: "Up for 14d 6h 23m")

Card 2: Average Latency & Response Time
  - Label: Response Time / Latency
  - Visual: Angka Latency saat ini (misal: "42 ms")
  - Subtext: Mini Sparkline Trend Chart (Pergerakan 1 jam terakhir)

Card 3: Overall Uptime Rate
  - Label: Service Availability
  - Visual: Persentase Uptime (misal: "99.95%")
  - Subtext: Calculated based on selected time-range

Card 4: Resource Overview / Health Summary
  - Tipe Server: Quick Mini Gauge (% CPU & % RAM saat ini)
  - Tipe Web/API/DB: HTTP Status Code (misal: "200 OK") / Port Status ("Listening")


3. MAIN ANALYTICS CHART AREA (STACKED AREA / LINE CHART)
----------------------------------------------------------------------
- Visual Style: Dark background, smooth bezier curves, gradient translucent fill, glowing lines.
- Dynamic Chart Display (Sesuai Tipe Target):

  A. Tipe Website / API Endpoint (Latency Breakdown - Stacked Area):
     * Layer 1 (Purple): DNS Lookup Time
     * Layer 2 (Blue): TCP Connect Time
     * Layer 3 (Cyan): TLS/SSL Handshake Time
     * Layer 4 (Teal): TTFB (Time to First Byte)
     * Layer 5 (Green): Content Download / Total Response Time

  B. Tipe Server Linux (System Resource - Multi-Line / Area):
     * Line 1: CPU Usage (%)
     * Line 2: RAM Usage (%)
     * Line 3: Disk I/O & Disk Space Used (%)
     * Line 4: Network Bandwidth (Upload/Download Speed in MB/s)
     * Line 5: Response Time / SSH Latency (ms) [Dual Y-Axis Scale]

- Tooltip Interactive: Hover kursor pada titik grafik akan memunculkan floating card 
  berisi timestamp presisi dan detail nilai tiap layer/metrik.


4. BOTTOM GRID SECTION (SPLIT 50% : 50%)
----------------------------------------------------------------------
Dibagi menjadi 2 kolom simetris pada layar desktop (responsif 1 kolom pada mobile):

A. Service & Port Health Matrix (Lebar 50%)
   - Grid internal 2 kolom (sm:grid-cols-2) dengan scrollbar internal (max-h: 300px)
   - Status badge anti-overflow (CONNECTED / LISTENING / CLOSED / UNREACHABLE)
   - Probe Latency per port / service

B. Card Riwayat Insiden & Downtime (Lebar 50%)
   - Header: Counter insiden + Live Status Indicator (🔴 "Insiden Aktif" atau 🟢 "Semua Normal")
   - Empty State: Tampilan tameng hijau saat target beroperasi 100% normal tanpa insiden
   - Daftar Insiden Terkini (scrollable max-h: 300px):
     * Status Badge: "SEDANG DOWN" (merah berkedip) jika aktif, "RESOLVED" (hijau) jika pulih
     * Rentang Waktu: Tanggal dan rentang jam mulai - selesai (WIB)
     * Durasi Downtime: Format kalkulasi dinamis (misal: "Downtime: 1 Jam 15 Menit" atau "45 Detik")
     * Keterangan Error: Catatan error (e.g. "Connection timed out" / "Connection refused")


5. LOGIC & BEHAVIOR ATURAN TAMPILAN
----------------------------------------------------------------------
- Silent Background Refresh: Auto-refresh data grafik, stat card, port matrix, dan insiden 
  berjalan di latar belakang secara mulus tanpa memunculkan overlay spinner "Memuat metrik..." 
  yang menutupi grafik. Overlay loading hanya muncul saat initial load atau ganti target/timeframe.
- Polling Dynamic Sync: Interval auto-refresh frontend otomatis tersinkronisasi mengikuti 
  setting polling_interval target aktif (10s/30s/60s/300s).
- Threshold Color Alerting:
  * Hijau  : Kondisi Normal (CPU/RAM < 80%, Latency normal, Status UP)
  * Kuning : Warning Threshold (CPU/RAM 80% - 94%, Latency tinggi)
  * Merah  : Critical / Incident (CPU/RAM >= 95%, Status DOWN / Port Closed)
- Mode Visualisasi: Toggle untuk memilih antara tampilan grafik Line Chart atau Stacked Area Chart.


6. SISTEM NOTIFIKASI TELEGRAM ALERT (HYBRID)
----------------------------------------------------------------------
- Trigger Otomatis:
  * Status ONLINE/PENDING -> OFFLINE : Kirim notifikasi 🔴 [SIM_MONIT ALERT] TARGET DOWN!
  * Status OFFLINE -> ONLINE         : Kirim notifikasi 🟢 [SIM_MONIT RECOVERY] TARGET BACK ONLINE! (lengkap durasi downtime)
- Anti-Spam: Siklus polling biasa yang tidak mengalami transisi status tidak akan mengirim pesan berulang.
- Mode Hybrid:
  * Mode "all"        : Menggunakan 1 Chat ID global untuk semua target.
  * Mode "per_target" : Menggunakan Chat ID spesifik sesuai preferensi per target.
- Proteksi Safe Execution: Jika toggle diaktifkan namun token atau chat ID kosong, sistem mengabaikan proses pengiriman secara senyap tanpa error.
- Fitur Test: Tombol "Test Kirim Pesan" di UI untuk validasi konektivitas bot ke Telegram secara langsung.
